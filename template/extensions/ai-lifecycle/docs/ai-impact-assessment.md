# AI Impact Assessment

Complete and approve this assessment before architecture for an AI-enabled product.

## Intended Use

Describe the user problem, intended uses, users, affected communities, and the
benefit the product is expected to provide.

## Prohibited Use

List prohibited uses, out-of-scope decisions, disallowed users, and situations
where the system must refuse or hand off to a person.

## Harm and Rights Assessment

Record foreseeable harm scenarios, applicable laws and policy, privacy impacts,
security impacts, fairness concerns, and the risk tolerance for each scenario.

## Oversight and Contestability

Define human oversight, approval points, escalation, user notice, contestability,
appeal, correction, and access to a human decision maker.
