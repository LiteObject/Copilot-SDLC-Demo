# AI Red-Team Plan

Perform risk-proportionate red teaming before high-impact releases and after
material changes. Track each finding through mitigation and retest.

## Scenario Catalog

Exercise prompt injection, sensitive information disclosure, supply chain
compromise, data or model poisoning, improper output handling, excessive agency,
system-prompt leakage, vector and retrieval weaknesses,
misinformation, unbounded consumption, jailbreaks, privacy leakage, bias,
insecure tool invocation, authorization bypass, and unsafe fallback behavior.
