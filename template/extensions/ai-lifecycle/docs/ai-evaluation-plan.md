# AI Evaluation Plan

Write this plan before implementation and rerun it for every material model,
prompt, retrieval, tool, data, or safety-policy change.

## Datasets and Method

Define representative and adversarial test datasets, sampling, ground truth,
measurement methodology, reviewer sampling, reproducibility, and privacy-safe
data handling.

## Measures and Thresholds

Measure task quality, reliability, grounding, hallucination and misinformation,
privacy, bias and fairness where applicable, robustness, prompt injection,
jailbreak resistance, insecure tool invocation, retrieval quality, and
refusal or fallback behavior. Define quality and safety thresholds, latency and
cost budgets, confidence intervals, and release-blocking criteria.
